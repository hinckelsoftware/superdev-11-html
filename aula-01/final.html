Sobre o SuperDev

O SuperDev é uma formação voltada para desenvolvimento de software, passando por tecnologias de front-end e back-end.

Nesta etapa estamos aprendendo a utilizar HTML para estruturar páginas web.

Módulos da formação

  • CSS
  • Git e GitHub
  • JavaScript e lógica de programação
  • Python
  • Banco de dados
